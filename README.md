# Sports Center Website

A database-backed sports center website developed as a university project by a team of three Computer Engineering students.

The project focused on building a functional website for managing sports center-related information, with emphasis on database design, backend support, testing, and integration with the web application.

---

## Overview

This project was created as part of a university course to design and develop a website for a sports center.

The system was built to support core sports center workflows and data management needs. My contribution focused mainly on the database side of the project, including database design, implementation, testing, and supporting integration with the website.

The final project was successfully delivered and positively evaluated by university professors.

---

This project was developed by a team of three Computer Engineering students.
